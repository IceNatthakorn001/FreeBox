# FreeBox

แอปจดบันทึกทุกเรื่องในชีวิต: รายรับ-รายจ่าย การบ้าน โน้ต ใช้ได้บน iPhone, iPad และคอม (เว็บแอป ติดตั้งลงหน้าจอโฮมได้)

เว็บ: (ใส่ลิงก์ Vercel ของคุณ)

## ทำอะไรได้

- **เงิน:** จดรายรับ-รายจ่าย ปุ่มจดเร็ว สรุปรายวัน/รายเดือนแยกหมวด ส่งออก CSV
- **อีเมลธนาคาร:** ดึงรายการจาก Gmail อัตโนมัติ เข้าหน้า "รอตรวจ" ก่อนนับยอด
- **การบ้าน:** วันส่ง เรียงใกล้ส่งก่อน เกินกำหนดเป็นสีแดง แจ้งเตือนเมื่อใกล้ส่ง
- **โน้ต:** ค้นหา ติดแท็ก กรองตามแท็ก
- **หน้าหลัก:** สรุปทุกอย่างในหน้าเดียว

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env   # แล้วใส่ค่า Supabase
npm run dev
```

ตั้งค่าครบทุกขั้น (Supabase, Vercel, อีเมลธนาคาร): [docs/SETUP.md](docs/SETUP.md)
โค้ดทำงานยังไง: [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md)

## เครื่องมือ

TypeScript · React + Vite · React Router · Supabase (PostgreSQL, Auth, RLS, Edge Functions) · Vercel · Google Apps Script

## กฎของโปรเจกต์

- เงินเก็บเป็นสตางค์ (จำนวนเต็ม) ใช้ฟังก์ชันใน `src/lib/money.ts`
- ส่วนคำนวณอยู่ใน `src/lib` ไม่ปนกับหน้าจอ
- เปลี่ยนตารางผ่านไฟล์ migration ใหม่เสมอ และเปิด RLS ทุกตาราง
- ลบแบบซ่อน (`deleted_at`) ไม่ลบจริง
- ห้าม commit ไฟล์ `.env`
