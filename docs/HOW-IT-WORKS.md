# FreeBox ทำงานยังไง

เอกสารนี้อธิบายภาพรวมของโค้ดทั้งหมด อ่านคู่กับคอมเมนต์ภาษาไทยในแต่ละไฟล์ ซึ่งอธิบายรายละเอียดทีละบรรทัด

## ภาพรวม: 3 ส่วนที่คุยกัน

```
┌──────────────── เครื่องผู้ใช้ (iPhone / iPad / คอม) ────────────────┐
│  หน้าเว็บ React (src/)                                             │
│  pages/ → hooks/ → lib/api.ts ──────────────┐                      │
│  public/sw.js เก็บไฟล์และข้อมูลไว้ใช้ตอนเน็ตหลุด  │                      │
└─────────────────────────────────────────────┼──────────────────────┘
                                              │ HTTPS + anon key + token ของผู้ใช้
┌──────────────── Supabase ───────────────────▼──────────────────────┐
│  Auth (ล็อกอิน)   PostgreSQL + RLS (supabase/migrations/)           │
│  Edge Function ingest-bank-email (supabase/functions/)  ◀───┐       │
└─────────────────────────────────────────────────────────────┼───────┘
                                                              │ x-ingest-secret
┌──────────────── Google (บัญชีของคุณ) ─────────────────────────┴──────┐
│  Gmail ป้าย "bank"  →  Apps Script (scripts/gmail-to-supabase.gs)   │
└─────────────────────────────────────────────────────────────────────┘
```

**หลักการสำคัญ:** ข้อมูลและกฎความปลอดภัยทั้งหมดอยู่ที่ Supabase หน้าเว็บเป็นแค่ตัวแสดงผล วันหนึ่งทำแอป iOS ก็ทำแค่หน้าจอใหม่ ต่อ Supabase ตัวเดิมได้เลย

## เส้นทางข้อมูล: ตัวอย่าง "กดจดเร็ว ข้าว 50 บาท"

1. `components/QuickAdd.tsx` ผู้ใช้กดหมวด "อาหาร" แล้วพิมพ์ `50`
2. `lib/money.ts` แปลง `"50"` เป็น `5000` สตางค์
3. `lib/api.ts` → `addTransaction()` ส่งคำสั่ง insert ไป Supabase พร้อม token ของผู้ใช้
4. Supabase ตรวจกฎ RLS: `user_id` ของแถวใหม่ต้องเท่ากับคนที่ล็อกอิน (ช่อง `user_id` มีค่า default เป็น `auth.uid()` เลยตรงเสมอ)
5. บันทึกสำเร็จ → `QuickAdd` เรียก `onAdded()` → `Home` สั่ง `reload()` → `lib/summary.ts` คิดยอดใหม่ → ตัวเลขบนการ์ดเปลี่ยน

## เส้นทางข้อมูล: อีเมลธนาคาร

1. ธนาคารส่งอีเมลแจ้งโอนเงิน → ฟิลเตอร์ Gmail ติดป้าย `bank`
2. ทุก 10 นาที Apps Script หาอีเมลป้าย `bank` ส่งไป Edge Function พร้อมรหัสลับ
3. Edge Function ตรวจรหัสลับ → `parseBankEmail()` อ่านยอด / รายรับหรือจ่าย / เลขอ้างอิง
4. บันทึกเป็น `status = 'pending'` (ยังไม่นับในยอด) ถ้าเลขอ้างอิงซ้ำ ข้ามไป ไม่เกิดรายการซ้ำ
5. Apps Script เปลี่ยนป้ายเป็น `bank-done`
6. เปิดแอป → จุดแดงบนเมนูเงิน → หน้า "รอตรวจ" → กดยืนยัน (แก้หมวด/ยอดได้) → กลายเป็น `confirmed` นับในยอด

ถ้าอ่านยอดไม่ออก รายการยังเข้าหน้ารอตรวจ โดยยอดเป็น 0 และโน้ตขึ้นว่า "อ่านยอดไม่ออก" ไม่หายเงียบ ๆ

## แนวคิดสำคัญที่ใช้ในโค้ด

### เงินเป็นสตางค์ (จำนวนเต็ม)
คอมพิวเตอร์บวกทศนิยมไม่เป๊ะ (`0.1 + 0.2 = 0.30000000000000004`) เลยเก็บ 45.50 บาท เป็น `4550` แล้วหาร 100 ตอนแสดงผลเท่านั้น

### RLS (Row Level Security)
anon key อยู่ในหน้าเว็บ ใครก็เห็นได้ สิ่งที่กันไม่ให้คนอื่นอ่านข้อมูลเราคือกฎในฐานข้อมูล: *อ่าน/เพิ่ม/แก้ได้เฉพาะแถวที่ `user_id = auth.uid()`* ไม่มีกฎ delete เลย ลบจากหน้าเว็บได้แค่แบบซ่อน

### ลบแบบซ่อน (soft delete)
กดลบ = ใส่เวลาใน `deleted_at` ทุกคำสั่งดึงข้อมูลกรอง `deleted_at is null` ข้อมูลจริงยังอยู่ ลบพลาดก็กู้ได้ที่ Supabase Table Editor (ลบค่า `deleted_at` ทิ้ง)

### แยก lib ออกจากหน้าจอ
`src/lib/` ไม่มี JSX ไม่มี React เป็นฟังก์ชันรับเข้า-คืนออก ทดสอบง่าย และยกไปใช้ใน React Native ได้ทั้งโฟลเดอร์

### Component + Props
หน้าจอแบ่งเป็นชิ้น ฟอร์มไม่รู้ว่าจะบันทึกไปไหน แค่เรียก `onSubmit` ที่ parent ส่งมา `TransactionForm` ตัวเดียวเลยใช้ได้ทั้งเพิ่ม แก้ และยืนยันรายการจากอีเมล

### state ที่ใช้หลายหน้าอยู่ชั้นบน
จำนวน "รอตรวจ" ใช้ทั้งเมนู หน้าหลัก และหน้าเงิน จึงเก็บใน `App.tsx` แล้วส่งลงไปเป็น props เมื่อหน้าลูกเปลี่ยนข้อมูล ก็เรียก `onChanged()` ให้ App นับใหม่

### useCallback + useLoad
`useLoad(loader)` โหลดใหม่ทุกครั้งที่ `loader` เปลี่ยน ถ้าไม่ห่อ loader ด้วย `useCallback` ฟังก์ชันจะถูกสร้างใหม่ทุกครั้งที่วาดหน้าจอ → โหลดวนไม่รู้จบ ส่วนหน้าเงินใส่ `[month]` ไว้ เปลี่ยนเดือน = loader ใหม่ = โหลดเดือนใหม่เอง

## เพิ่มตัวอ่านธนาคาร

ตัวอ่านทั่วไปเดาจากคำที่พบบ่อย ใช้ได้กับหลายธนาคาร แต่ถ้าอยากให้แม่นขึ้น:

1. เปิดอีเมลจริงจากธนาคาร 3–5 ฉบับ ดูว่ายอดเงินกับเลขอ้างอิงเขียนแบบไหน
2. เปิด `supabase/functions/_shared/parseBankEmail.ts` ลบ `//` ในตัวอย่าง `myBankParser` แล้วแก้ regex ให้ตรง
3. ใส่ชื่อ parser ใน `BANK_PARSERS`
4. deploy Edge Function ใหม่ (ดู docs/SETUP.md ขั้นที่ 6)

## ข้อจำกัดที่รู้อยู่

- **แจ้งเตือนการบ้าน** เด้งตอนเปิดแอปเท่านั้น การเด้งตอนปิดแอป (Web Push) ต้องมีเซิร์ฟเวอร์ส่ง เก็บไว้ทำตอนเป็นแอปจริง
- **เน็ตหลุด** ดูข้อมูลล่าสุดที่เคยโหลดได้ แต่เพิ่ม/แก้ไม่ได้
- **โน้ต** เป็นข้อความธรรมดา ยังไม่แสดงผล Markdown
- **บัญชีเดียว** Edge Function บันทึกอีเมลให้ผู้ใช้คนเดียว (`OWNER_USER_ID`) เพราะเป็นแอปส่วนตัว
